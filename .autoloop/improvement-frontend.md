# 前端可用性与无障碍复盘

更新时间：2026-11-26

## 已修复

- 制作档案列表不再把 API 失败误显示为“没有匹配的制作档案”。现在有加载状态、错误提示和“重试”按钮，避免明早操作时误判为空数据。
- 制作档案列表请求使用 `cache: "no-store"`，并在卸载时停止更新状态，避免旧请求覆盖新页面。
- 参考产品图标与商店截图补齐宽高、懒加载和异步解码，减少图片加载造成的布局位移。
- 移除总览页未使用的 `latest` 变量，补充远程图片使用原生 `<img>` 的明确 lint 例外说明。

## 验证

- `npm run lint` 通过，0 warning、0 error。
- `npm test` 通过，生产构建与 15 项静态测试全部通过。
- 已检查启动选品、任务板、选品总表、报告详情、制作档案和报告导入路径。

## 明早操作路径结论

- 启动选品页有服务端错误提示、重试、状态筛选、任务轮询和完成报告链接。
- 选品总表筛选保持在 URL 查询参数中，可复制和返回后复现。
- 制作档案筛选目前是客户端状态，刷新页面会回到默认筛选。它不阻塞单次使用，后续可同步到 URL。
- YouTube 证据在报告详情和制作档案中展示，`found` 显示最多两个视频入口，`insufficient_data` 显示范围与限制。
- 远程参考图片已有尺寸和懒加载，页面保留无图片时的文字占位。
- 页面已有 skip link、语义导航、表单标签、可见 focus 样式和异步状态提示。

## 后续建议

- 制作档案筛选、分页和搜索同步到 URL，便于团队共享具体视图。
- 制作档案保存和复制提示词增加进行中状态与失败后的重试入口。当前失败信息会显示在状态提示中，连续 blur 保存仍可能产生并发请求。
- 选品任务轮询在组件卸载或网络错误时增加 AbortController 与可见的轮询失败提示。
- 报告详情的自定义 `role="table"` 可在后续改为原生 `<table>` 或补充完整 row/column 语义，提升屏幕阅读器一致性。
