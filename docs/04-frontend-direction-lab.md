# 前端设计实验室：方向评审基线

上一轮三套方案已被用户否决，不进入生产。它们仍保留作反例和交互契约样本。新的参考标的与方向见：[参考标的分析](10-reference-benchmark.md)。设计对比入口：[design/index.html](../design/index.html)。

## A · 深海指挥台 / Deep Sea Control

- 视觉主张：把容量、队列和风险做成一张可呼吸的控制海图。
- 页面轮廓：左侧导航轨 + 中央任务海图 + 右侧负责人和容量面板。
- 类型声音：窄体无衬线用于状态与数据，宽字重标题用于决策动作。
- 色彩：深海蓝 `#071521`、雾蓝 `#19384b`、海沫青 `#77e2d1`、珊瑚警示 `#ff8364`、月白 `#eaf3ef`。
- 材质：深色金属与微弱网格，状态用荧光边缘而不是大色块。
- 动效：队列脉冲、容量环轻微呼吸；尊重 reduced motion。
- 签名时刻：全局容量环的“潮汐线”随进行中任务变化。
- 风险：深色长时使用对低对比度文字敏感，必须保留高对比模式。

## B · 纸本运营室 / Editorial Ledger

- 视觉主张：把每项选品当作一条有负责人、有证据、有结论的运营记录。
- 页面轮廓：顶部周期标题 + 分栏账簿 + 可展开任务卡，不使用传统 Dashboard 卡片墙。
- 类型声音：高对比衬线标题配人文无衬线正文，等宽数字只用于审计和时间。
- 色彩：骨白 `#f6f1e7`、墨黑 `#1e211d`、松绿 `#3c6d5b`、赭石 `#b66a43`、纸灰 `#d7d1c5`。
- 材质：纸张、细线、印章式状态标签；没有玻璃拟态。
- 动效：翻页式展开、证据抽屉平滑出现；操作后保留清晰的落笔反馈。
- 签名时刻：每项任务的“证据索引”像书脊一样贯穿列表。
- 风险：信息密度高，移动端必须改为单列时间线。

## C · 琥珀工坊 / Amber Forge

- 视觉主张：让“认领 → 研究 → 回执”像一条可见的工坊生产线。
- 页面轮廓：横向工作台、泳道式任务流、右侧快速发起抽屉。
- 类型声音：几何显示字体用于阶段标题，清晰的中性无衬线用于长文本。
- 色彩：石墨 `#171817`、琥珀 `#f0a84b`、铜红 `#c55a42`、粉尘灰 `#9a9e96`、温白 `#f5efe2`。
- 材质：拉丝金属、纸标签、实心阶段节点；用阴影表达层级而不是渐变。
- 动效：拖拽认领、节点吸附、完成时短促的机械确认音效（默认静音）。
- 签名时刻：任务被认领时，从队列轨道滑入负责人的工作台并显示剩余容量。
- 风险：生产线隐喻容易把研究工作误解为线性生产，必须在详情页展示阻塞与证据缺口。

## 上一轮结论（已废弃）

上一轮的 A/B/C 都有通用 Dashboard、装饰性进度环、圆角卡片和缺少对象关系的问题。不得因为局部颜色或圆角调整就把它们重新包装为新方案；下一轮直接从 D/E/F 三个方向重新设计。

## 新增视觉资料要求

候选列表、报告详情和制作档案都要把“看得懂对象”作为首要任务。每个候选至少显示一个可追溯图标或明确的生成图标状态，并在有来源时显示参考产品商店图标、样图和 YouTube 视频入口。视频和样图旁边要保留来源、检索/抓取时间与关联对象；找不到素材时显示可复核的缺口状态。
