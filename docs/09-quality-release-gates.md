# 质量与发布门禁

## 功能

- 发起任务的幂等键重复提交不产生重复任务。
- 自动分派不超过基础容量；认领不超过额外 2 个；全局进行中量不超过硬上限。
- 两个用户同时认领同一任务只有一个成功。
- 租约失联可回收，重复回收不重复分派。
- 完成必须有业务回执、产物校验和审计记录。

## 安全

- API 需要身份与角色授权；管理员操作单独审计。
- Webhook、Token、Cookie 和服务器密钥只从 Secret 注入。
- 执行器在沙箱、白名单和最小权限下运行；Web 请求不能直接执行 Shell。
- 日志脱敏，不能输出 Webhook、访问令牌或完整用户隐私数据。

## 发布

- `npm test` / `npm run lint` / 类型检查通过。
- Docker 镜像可重建，迁移可重复，健康接口可读。
- staging canary 验证登录、任务、分派、报告、下载、Feishu 回执。
- 保存版本、提交、镜像、迁移、健康检查和回滚证据。
