# YouTube 视频证据与视觉资料规范

## 目的

让选品人员打开候选时，能一眼识别产品或游戏，并能直接进入关联视频观察真实玩法、界面、节奏和用户表达。

## 必做流程

1. 选品候选完成路线筛选后，搜索 YouTube。
2. 使用候选英文名、中文名、唯一主竞品、参考对象和玩法关键词组合检索。
3. 游戏额外使用 `gameplay`、`walkthrough`、`trailer`、`review`、`hands-on` 等词。
4. 优先记录官方频道、开发者频道、发行商频道和可确认的实机或评测来源。
5. 保存具体视频 URL、标题、频道、发布时间、关联类型、对象、检索时间和核验说明。
6. 在候选页面、报告详情和制作档案显示视频入口。页面同时显示候选图标、参考产品图标和可用的商店截图或样图。

## 找不到视频时

找不到可确认的视频时，记录使用过的检索词、检索时间、搜索范围、访问限制和下一步补证动作，并标记 `insufficient_data`。搜索页、频道页或模型生成的猜测链接不能替代具体视频 URL。

## 开工提示词门禁

每份开工提示词都必须包含以下要求：

> 开始设计和编码前，先搜索 YouTube 上与候选、主竞品和玩法相关的视频。记录具体视频链接、标题、频道、发布时间、视频类型和可观察到的事实。找到的视频作为玩法、界面、节奏和痛点研究输入。找不到时记录检索范围和 `insufficient_data`，不得虚构链接。

执行回执缺少 YouTube 检索记录时，开工包标记为 `partial` 或 `blocked`，不得标记为完成。

## 版权与来源

视频链接用于研究和核验。系统保存来源、时间和事实摘要，不下载或重新发布受保护视频。候选自身的图标和样图需要标注来源，无法确认来源时显示待补状态。
