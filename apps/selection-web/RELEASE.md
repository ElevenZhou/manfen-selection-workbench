# 满分选品驾驶舱 v1.0.0

封板日期：2026-11-24（Asia/Singapore）

## 封板内容

- 统一报告、候选、生产资料包、项目档案和开发排期入口。
- 三条选品路线保持独立，支持报告入库、候选筛选和资料包下载。
- 飞书推送在服务端执行，使用报告级幂等键，密钥只从环境变量读取。
- 选品工作器的正式站点默认地址为 `https://select.1add2.com`。
- 当前发布版本为 `v1.0.0`，后续修订使用新的版本号和 Git tag。
