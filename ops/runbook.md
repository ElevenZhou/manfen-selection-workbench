# 运维 Runbook

## 日常检查

1. `/api/health` 返回数据库、队列、对象存储和执行器状态。
2. 检查队列积压、租约超时、失败率、磁盘和最近备份。
3. 检查 `completed` 任务是否都有报告/产物和业务回执。
4. 检查 Feishu 失败是否集中在同一报告、同一时间或同一凭据。

## 任务卡死

- 先暂停新任务派发，读取任务租约、最后心跳和执行器日志。
- 如果没有外部副作用，回收租约并重派；如果已经写外部系统，转人工复核。
- 保留原负责人、执行器、错误摘要和恢复动作，不覆盖旧事件。

## Feishu 失败

- 不自动重复发送。
- 读取报告是否已入库、卡片是否已生成、HTTP 与业务 code 是否成功。
- 修复配置后使用同一幂等键明确重试，保存新的回执事件。

## 回滚

- 停止新任务；保留现有 Worker 心跳和审计。
- 回滚应用镜像或前向修复迁移；读回健康接口和任务计数。
- 逐步恢复 canary，确认完成门禁和 Feishu 链接后再放量。
