Read every file in this package. Freeze the scope, core change directions, and
three-perspective acceptance criteria before coding.

Stage: `PROTOTYPE`
Stack: React Native / Expo, TypeScript, 本地优先存储, 事件分析适配层

Recommended skills: auto-loop, frontend-studio, vercel-react-best-practices

构建 Fair Screw（公平螺丝） 的48小时可玩灰盒。目标用户是喜欢短局空间解谜、但反感人为卡关和强制广告的休闲玩家。核心任务是通过可读的空间规则解开螺丝谜题，而不是依赖付费道具或反复重试。产品承诺是保留螺丝解谜的满足感，但每局失败都能解释为可学习的选择。严格只实现资料包列出的核心改变；先冻结任务流、数据边界和验收标准，再实现、测试并检查真实界面。所有AI输出必须展示不确定性或来源；网络失败不得破坏本地核心任务。

## Required deliverables

- 可运行源代码
- 核心流程自动化测试
- 关键屏幕截图
- 事件字典
- 已知风险与下一阶段建议

## Allowed autonomy

- 可在既定范围内选择组件和库
- 可修复测试、性能和无障碍问题
- 可优化文案但不得扩大功能

## Pause conditions

- 需要付费服务或新凭据
- 需要公开部署或商店提交
- 范围变更影响产品承诺
- 涉及医疗、安全或隐私高风险决定
