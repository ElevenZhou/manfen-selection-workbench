# Product brief

## Objective

- 产品形态：手机游戏
- Target markets: Global
- Target platforms: iOS, Android
- Target user: 希望把自己的照片变成短局拼块挑战的休闲玩家
- Trigger: 拍到宠物、旅行或家庭照片并想立刻得到一个可玩的分享物
- Core job: 在不上传私人照片的情况下生成一局可玩的块状拼图
- Current alternative: Block Puzzle、传统照片拼图和社交平台滤镜
- Product promise: 照片在设备端转成可解的60秒块状关卡，分享的是关卡种子而非原图
- Minimum success: 完成30人灰盒方向测试并形成留存假设

## Core change directions

### 1. 端侧分析照片主体并生成三档可解布局

- User evidence: 参考组与公开用户证据共同指向：Block Puzzle、传统照片拼图和社交平台滤镜尚未稳定解决该结果。
- Current failure: Block Puzzle、传统照片拼图和社交平台滤镜
- Change: 端侧分析照片主体并生成三档可解布局
- Expected outcome: 减少核心任务的步骤、等待、误触或不确定性，并能在最小版本中直接测量。
- Validation metric: 任务完成率、完成时间、错误/退出率及目标用户主观可信度。
- Out of scope: 不扩展为全能平台，不复制竞品品牌、内容、关卡、代码或受保护资产。

## Scope

- 端侧分析照片主体并生成三档可解布局
- 分享默认只传布局和色块特征，原图保持本地
- 核心流程埋点、空状态、错误状态和隐私说明

- 不做全品类平台

- 未授权不公开部署、不提交商店、不购买服务
