# 休闲游戏专项 2+2+2

- Run ID: `2026-07-25-casual-games-2x2x2`
- 方向：casual-games
- 数据方式：联网大模型现用现查；没有持续爬虫；公开证据不等于付费供应商精确指标。
- 路线：A、B、C独立评分和排名，不做跨路线总分。

## 本轮结论

### Route A · 2个

#### 1. Fair Screw · 82/100

- 用户：喜欢短局空间解谜、但反感人为卡关和强制广告的休闲玩家
- 核心任务：通过可读的空间规则解开螺丝谜题，而不是依赖付费道具或反复重试
- 机会：保留螺丝解谜的满足感，但每局失败都能解释为可学习的选择
- 参考：[Screw Jam](https://play.google.com/store/apps/details?id=com.quok.screwJam), [Screw Wood Nuts & Bolts](https://play.google.com/store/apps/details?id=com.funspace.screw), [Screw Jam Handler](https://play.google.com/store/apps/details?id=screw.jam.handler)
- 改进：关卡开始前展示可用槽位和失败因果，失败后给一步回放；奖励广告只出现在自然停顿点，不把必需槽位锁在广告后
- 下一验证：游戏招募至少30名方向性玩家；非游戏完成5–8名目标用户任务测试并测量核心结果。

#### 2. Calm Sort · 79/100

- 用户：喜欢整理与三消反馈、但不喜欢计时压迫和视觉杂乱的成年玩家
- 核心任务：通过视觉整理获得完成感，并清楚知道下一步而不是被遮挡和倒计时惩罚
- 机会：用无计时主模式和高可读货架，保留三件匹配的整理满足感
- 参考：[Goods Triple Match](https://play.google.com/store/apps/details?id=com.goods.sorting.games.triple.match3d.puzzle), [Match Factory](https://play.google.com/store/apps/details?id=net.peakgames.match), [Triple Match 3D](https://play.google.com/store/apps/details?id=com.master.triple3d.find)
- 改进：主模式不设倒计时，挑战计时作为可选玩法；高对比轮廓与遮挡提示降低误触，广告仅在局间
- 下一验证：游戏招募至少30名方向性玩家；非游戏完成5–8名目标用户任务测试并测量核心结果。

### Route B · 2个

#### 1. Merge Minute · 83/100

- 用户：喜欢合成成长、但只有三到五分钟且不愿被体力等待打断的玩家
- 核心任务：在固定短时段内完成一次有结尾的合成任务
- 机会：每局三分钟有明确结尾，长期叙事是奖励而不是阻止继续玩的门槛
- 参考：[Merge Mansion](https://apps.apple.com/us/app/merge-mansion-puzzles-story/id1484442152), [Travel Town](https://play.google.com/store/apps/details?id=io.randomco.travel), [Gossip Harbor](https://play.google.com/store/apps/details?id=com.mergegames.gossipharbor)
- 改进：固定三分钟任务板，完成或失败都结算，不用等待能量继续核心玩法；长期元进度使用可选章节，不用强制弹窗打断合成
- 下一验证：游戏招募至少30名方向性玩家；非游戏完成5–8名目标用户任务测试并测量核心结果。

#### 2. Duo Shelf · 80/100

- 用户：异地朋友或伴侣，想用轻量游戏保持日常联系但不想实时约局
- 核心任务：异步合作完成一个两分钟整理任务，并留下可见的接力痕迹
- 机会：把单人整理变成无需同时在线的每日双人接力
- 参考：[Goods Triple Match](https://play.google.com/store/apps/details?id=com.goods.sorting.games.triple.match3d.puzzle), [Plato](https://platoapp.com/), [Discord Activities](https://discord.com/activities)
- 改进：每人完成货架的一半，另一人可看到对方留下的提示和失误；每日只推送一次可完成接力，不建立重社交系统
- 下一验证：游戏招募至少30名方向性玩家；非游戏完成5–8名目标用户任务测试并测量核心结果。

### Route C · 2个

#### 1. Daily Scene · 80/100

- 用户：喜欢Wordle或GeoGuessr式每日一次分享，但希望更视觉化的轻量玩家
- 核心任务：从逐步揭示的场景线索猜地点、事件或主题并分享不剧透结果
- 机会：每天一个可验证来源的视觉谜题，三次揭示内完成并可无剧透分享
- 参考：[NYT Games](https://www.nytimes.com/crosswords), [GeoGuessr](https://www.geoguessr.com/), [Apple Core AI](https://developer.apple.com/core-ai/)
- 改进：AI只用于生成干扰线索和难度变体，谜底与事实由编辑数据确认；分享卡只展示揭示次数和推理路径，不泄露答案
- 下一验证：游戏招募至少30名方向性玩家；非游戏完成5–8名目标用户任务测试并测量核心结果。

#### 2. Snap Blocks · 78/100

- 用户：希望把自己的照片变成短局拼块挑战的休闲玩家
- 核心任务：在不上传私人照片的情况下生成一局可玩的块状拼图
- 机会：照片在设备端转成可解的60秒块状关卡，分享的是关卡种子而非原图
- 参考：[AppMagic Mobile Market Landscape 2026](https://appmagic.rocks/files/view/upload/Reports/EN_MobileMarkeLandscape2026.pdf), [Apple Core AI](https://developer.apple.com/core-ai/), [Block Blast](https://play.google.com/store/apps/details?id=com.block.juggle)
- 改进：端侧分析照片主体并生成三档可解布局；分享默认只传布局和色块特征，原图保持本地
- 下一验证：游戏招募至少30名方向性玩家；非游戏完成5–8名目标用户任务测试并测量核心结果。
