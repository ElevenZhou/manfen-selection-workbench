# Product brief

## Objective

- 产品形态：Web 应用
- Target markets: Global
- Target platforms: Web
- Target user: 需要持续跟踪行业专家、研究员和高影响账号观点变化的投资、战略与研究团队
- Trigger: 关注对象改变结论、给出新催化剂、撤回旧判断，或同一主题的高质量观点出现明显分歧
- Core job: 识别谁在何时改变了什么判断、依据是什么，并把变化而不是所有帖子推给团队
- Current alternative: Kaito Pro、Santiment、LunarCrush以及X列表和人工截图归档
- Product promise: 把KOL信息流转换为可回溯的观点版本、证据变化和低噪声推送，而不是再做一张热度榜
- Minimum success: 5–8名目标用户中至少70%独立完成核心任务，且核心结果优于现有替代。

## Core change directions

### 1. 按人和主题维护观点版本，只在结论、置信度、时间窗口或关键依据变化时生成差异卡

- User evidence: 参考组与公开用户证据共同指向：Kaito Pro、Santiment、LunarCrush以及X列表和人工截图归档尚未稳定解决该结果。
- Current failure: Kaito Pro、Santiment、LunarCrush以及X列表和人工截图归档
- Change: 按人和主题维护观点版本，只在结论、置信度、时间窗口或关键依据变化时生成差异卡
- Expected outcome: 减少核心任务的步骤、等待、误触或不确定性，并能在最小版本中直接测量。
- Validation metric: 任务完成率、完成时间、错误/退出率及目标用户主观可信度。
- Out of scope: 不扩展为全能平台，不复制竞品品牌、内容、关卡、代码或受保护资产。
### 2. 推送同时展示原文、反方证据和AI不确定性，不把情绪或互动量直接写成事实

- User evidence: 参考组与公开用户证据共同指向：Kaito Pro、Santiment、LunarCrush以及X列表和人工截图归档尚未稳定解决该结果。
- Current failure: Kaito Pro、Santiment、LunarCrush以及X列表和人工截图归档
- Change: 推送同时展示原文、反方证据和AI不确定性，不把情绪或互动量直接写成事实
- Expected outcome: 减少核心任务的步骤、等待、误触或不确定性，并能在最小版本中直接测量。
- Validation metric: 任务完成率、完成时间、错误/退出率及目标用户主观可信度。
- Out of scope: 不扩展为全能平台，不复制竞品品牌、内容、关卡、代码或受保护资产。

## Scope

- 按人和主题维护观点版本，只在结论、置信度、时间窗口或关键依据变化时生成差异卡
- 推送同时展示原文、反方证据和AI不确定性，不把情绪或互动量直接写成事实
- 核心流程埋点、空状态、错误状态和隐私说明

## Non-goals

- 不做全品类平台
- 不复制参考产品资产
- 未授权不公开部署、不提交商店、不购买服务
