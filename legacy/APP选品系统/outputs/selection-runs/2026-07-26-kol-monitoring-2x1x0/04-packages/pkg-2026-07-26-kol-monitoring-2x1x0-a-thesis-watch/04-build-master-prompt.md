# Build master prompt

Read every file in this package. Freeze the scope, core change directions, and
three-perspective acceptance criteria before coding.

Objective: 把KOL信息流转换为可回溯的观点版本、证据变化和低噪声推送，而不是再做一张热度榜
Stage: `MVP`
Stack: React Native / Expo, TypeScript, 本地优先存储, 事件分析适配层
Repository: create or select within the authorized workspace
Recommended skills: auto-loop, frontend-studio, vercel-react-best-practices

构建 Thesis Watch（观点追踪）的可测试MVP。目标用户是需要持续跟踪行业专家、研究员和高影响账号观点变化的投资、战略与研究团队。核心任务是识别谁在何时改变了什么判断、依据是什么，并把变化而不是所有帖子推给团队。产品承诺是把KOL信息流转换为可回溯的观点版本、证据变化和低噪声推送，而不是再做一张热度榜。严格只实现资料包列出的核心改变；先冻结任务流、数据边界和验收标准，再实现、测试并检查真实界面。所有AI输出必须展示不确定性或来源；网络失败不得破坏本地核心任务。

## Required deliverables

- 可运行源代码
- 核心流程自动化测试
- 关键屏幕截图
- 事件字典
- 已知风险与下一阶段建议

## Allowed autonomy

- 可在既定范围内选择组件和库
- 可修复测试、性能和无障碍问题
- 可优化文案但不得扩大功能

## Pause conditions

- 需要付费服务或新凭据
- 需要公开部署或商店提交
- 范围变更影响产品承诺
- 涉及医疗、安全或隐私高风险决定
