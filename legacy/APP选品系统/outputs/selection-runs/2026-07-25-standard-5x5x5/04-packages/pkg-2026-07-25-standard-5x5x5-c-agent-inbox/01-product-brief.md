# Product brief

## Objective

- 产品形态：跨端应用
- Target markets: Global
- Target platforms: Web, macOS, Windows, iOS, Android
- Target user: 同时使用多个AI代理和自动化工作流的个人与小团队
- Trigger: 代理准备发送消息、付款、发布、删除或修改外部系统
- Core job: 在一个地方看到真正需要人决定的动作、依据、风险和撤回窗口
- Current alternative: 逐个工具通知、Slack审批、邮件和自动化运行日志
- Product promise: 把人从盯代理运行变成只处理少量可解释的决策
- Minimum success: 5–8名目标用户中至少70%独立完成核心任务，且核心结果优于现有替代。

## Core change directions

### 1. 统一聚合高风险待确认动作，默认隐藏无须干预的执行日志

- User evidence: 参考组与公开用户证据共同指向：逐个工具通知、Slack审批、邮件和自动化运行日志尚未稳定解决该结果。
- Current failure: 逐个工具通知、Slack审批、邮件和自动化运行日志
- Change: 统一聚合高风险待确认动作，默认隐藏无须干预的执行日志
- Expected outcome: 减少核心任务的步骤、等待、误触或不确定性，并能在最小版本中直接测量。
- Validation metric: 任务完成率、完成时间、错误/退出率及目标用户主观可信度。
- Out of scope: 不扩展为全能平台，不复制竞品品牌、内容、关卡、代码或受保护资产。
### 2. 每项展示来源、影响面、可逆性和撤回截止时间

- Current failure: 逐个工具通知、Slack审批、邮件和自动化运行日志
- Change: 每项展示来源、影响面、可逆性和撤回截止时间

## Scope

- 统一聚合高风险待确认动作，默认隐藏无须干预的执行日志
- 每项展示来源、影响面、可逆性和撤回截止时间
- 核心流程埋点、空状态、错误状态和隐私说明

## Non-goals

- 不做全品类平台
- 不复制参考产品资产
- 未授权不公开部署、不提交商店、不购买服务
