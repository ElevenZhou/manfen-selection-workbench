# Product brief

## Objective

- 产品形态：桌面 App
- Target markets: Global
- Target platforms: macOS, Windows
- Target user: 在多个云端和本地模型之间切换的重度AI用户
- Trigger: 完成一次重要任务、产生高成本调用或输入敏感内容
- Core job: 知道哪个任务用了哪个模型、花了多少、数据去了哪里、结果能否复现
- Current alternative: OpenRouter用量页、Open WebUI、LM Studio和个人表格
- Product promise: 跨模型自动生成成本、隐私和结果可追溯的任务账本
- Minimum success: 5–8名目标用户中至少70%独立完成核心任务，且核心结果优于现有替代。

## Core change directions

### 1. 按任务而非按API调用记录模型、费用和结果版本

- User evidence: 参考组与公开用户证据共同指向：OpenRouter用量页、Open WebUI、LM Studio和个人表格尚未稳定解决该结果。
- Current failure: OpenRouter用量页、Open WebUI、LM Studio和个人表格
- Change: 按任务而非按API调用记录模型、费用和结果版本
- Expected outcome: 减少核心任务的步骤、等待、误触或不确定性，并能在最小版本中直接测量。
- Validation metric: 任务完成率、完成时间、错误/退出率及目标用户主观可信度。
- Out of scope: 不扩展为全能平台，不复制竞品品牌、内容、关卡、代码或受保护资产。
### 2. 发送敏感内容前显示本地/云端路径和保留策略

- User evidence: 参考组与公开用户证据共同指向：OpenRouter用量页、Open WebUI、LM Studio和个人表格尚未稳定解决该结果。
- Current failure: OpenRouter用量页、Open WebUI、LM Studio和个人表格
- Change: 发送敏感内容前显示本地/云端路径和保留策略
- Expected outcome: 减少核心任务的步骤、等待、误触或不确定性，并能在最小版本中直接测量。
- Validation metric: 任务完成率、完成时间、错误/退出率及目标用户主观可信度。
- Out of scope: 不扩展为全能平台，不复制竞品品牌、内容、关卡、代码或受保护资产。

## Scope

- 按任务而非按API调用记录模型、费用和结果版本
- 发送敏感内容前显示本地/云端路径和保留策略
- 核心流程埋点、空状态、错误状态和隐私说明

## Non-goals

- 不做全品类平台
- 不复制参考产品资产
- 未授权不公开部署、不提交商店、不购买服务
