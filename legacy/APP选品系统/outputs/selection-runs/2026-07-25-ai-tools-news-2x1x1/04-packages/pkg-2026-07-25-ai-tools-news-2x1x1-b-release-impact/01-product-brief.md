# Product brief

## Objective

- 产品形态：Web 应用
- Target markets: Global
- Target platforms: Web
- Target user: 依赖多个AI模型、SDK、开源项目和平台API的小型开发团队
- Trigger: 供应商发布模型、API、价格、废弃或安全更新
- Core job: 知道这次变化影响自己的哪些仓库、功能和截止日期
- Current alternative: GitHub Watch、RSS/Feedly、供应商邮件和人工维护依赖表
- Product promise: 把发布信息从“我看过”变成与代码和产品相连的影响清单
- Minimum success: 5–8名目标用户中至少70%独立完成核心任务，且核心结果优于现有替代。

## Core change directions

### 1. 把Release与项目清单匹配，只输出受影响依赖和迁移动作

- User evidence: 参考组与公开用户证据共同指向：GitHub Watch、RSS/Feedly、供应商邮件和人工维护依赖表尚未稳定解决该结果。
- Current failure: GitHub Watch、RSS/Feedly、供应商邮件和人工维护依赖表
- Change: 把Release与项目清单匹配，只输出受影响依赖和迁移动作
- Expected outcome: 减少核心任务的步骤、等待、误触或不确定性，并能在最小版本中直接测量。
- Validation metric: 任务完成率、完成时间、错误/退出率及目标用户主观可信度。
- Out of scope: 不扩展为全能平台，不复制竞品品牌、内容、关卡、代码或受保护资产。
### 2. 高风险废弃、价格或权限变化生成负责人和截止时间

- User evidence: 参考组与公开用户证据共同指向：GitHub Watch、RSS/Feedly、供应商邮件和人工维护依赖表尚未稳定解决该结果。
- Current failure: GitHub Watch、RSS/Feedly、供应商邮件和人工维护依赖表
- Change: 高风险废弃、价格或权限变化生成负责人和截止时间
- Expected outcome: 减少核心任务的步骤、等待、误触或不确定性，并能在最小版本中直接测量。
- Validation metric: 任务完成率、完成时间、错误/退出率及目标用户主观可信度。
- Out of scope: 不扩展为全能平台，不复制竞品品牌、内容、关卡、代码或受保护资产。

## Scope

- 把Release与项目清单匹配，只输出受影响依赖和迁移动作
- 高风险废弃、价格或权限变化生成负责人和截止时间
- 核心流程埋点、空状态、错误状态和隐私说明

## Non-goals

- 不做全品类平台
- 不复制参考产品资产
- 未授权不公开部署、不提交商店、不购买服务
