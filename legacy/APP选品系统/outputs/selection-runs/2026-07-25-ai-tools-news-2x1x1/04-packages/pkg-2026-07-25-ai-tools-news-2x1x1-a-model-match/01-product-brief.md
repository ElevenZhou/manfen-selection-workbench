# Product brief

## Objective

- 产品形态：Web 应用
- Target markets: Global
- Target platforms: Web
- Target user: 需要为真实任务选择模型、但不想在多个订阅和聊天记录间比较的AI重度用户
- Trigger: 准备执行写作、代码、研究、图像或隐私敏感任务
- Core job: 用同一个任务样本比较少量适合的模型，并保留成本与结果依据
- Current alternative: Poe、OpenRouter、ChatHub
- Product promise: 围绕任务做小规模可复现对比，而不是提供又一个无限模型聊天列表
- Minimum success: 5–8名目标用户中至少70%独立完成核心任务，且核心结果优于现有替代。

## Core change directions

### 1. 先按任务和约束推荐三种模型，再用同一评测清单对比

- User evidence: 参考组与公开用户证据共同指向：Poe、OpenRouter、ChatHub尚未稳定解决该结果。
- Current failure: Poe、OpenRouter、ChatHub
- Change: 先按任务和约束推荐三种模型，再用同一评测清单对比
- Expected outcome: 减少核心任务的步骤、等待、误触或不确定性，并能在最小版本中直接测量。
- Validation metric: 任务完成率、完成时间、错误/退出率及目标用户主观可信度。
- Out of scope: 不扩展为全能平台，不复制竞品品牌、内容、关卡、代码或受保护资产。

## Scope

- 先按任务和约束推荐三种模型，再用同一评测清单对比
- 保存提示词、版本、耗时、成本和用户选择理由

## Non-goals

- 不做全品类平台
- 不复制参考产品资产
- 未授权不公开部署、不提交商店、不购买服务
