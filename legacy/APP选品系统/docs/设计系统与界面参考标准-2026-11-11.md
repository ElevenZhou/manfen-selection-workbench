# APP 选品系统设计系统与界面参考标准

日期：2026-11-11  
版本：v1.0  
状态：作为后续页面设计与实现的视觉基准

## 1. 参考主稿

综合选品数据看板第三版是当前主视觉标准：

[portfolio-dashboard-opportunity-map-v3-2026-11-11.png](/Users/xmm/projects/APP选品系统/design/portfolio-dashboard-opportunity-map-v3-2026-11-11.png)

它定义了以下共同语言：

- 深夜蓝侧栏 + 暖象牙色工作区；
- 中央机会分布地图作为决策页面的视觉锚点；
- 四类机会使用稳定色彩：App 蓝、游戏陶土红、跨平台迁移玉绿色、日常热点金色；
- 纸张质感、细线、留白和编辑型排版；
- 重要数字使用高对比衬线/显示字体，状态和元数据使用紧凑无衬线字体；
- 信息密度高，但每个模块都必须服务于一个决策动作；
- 右侧用于关注项、风险、选中对象和下一步动作；
- 底部用于队列、时间线和可回溯记录。

## 2. 页面统一骨架

```text
左侧导航
  → 页面标题 / 时间范围 / 数据新鲜度
  → 当前页面核心决策区
  → 证据、状态、负责人、下一步动作
  → 可筛选队列或时间线
```

每页都必须有：

- 当前数据截止时间；
- 数据质量或证据完整度；
- 当前对象状态；
- 负责人和截止时间（适用于项目/任务）；
- 可执行的下一步动作；
- 返回来源、报告、运行或证据的链接。

## 3. 颜色与语义

| 语义 | 颜色 | 使用范围 |
|---|---|---|
| App | 皇家蓝 | App 机会、标签、路线和图表 |
| 游戏 | 陶土红 | 游戏机会、标签、风险 |
| 跨平台迁移 | 玉绿色 | 源平台→目标平台、迁移矩阵 |
| 日常与热点 | 金黄色 | 热点信号、时效、短周期机会 |
| 通过/已验证 | 深绿色 | 证据通过、QA 通过、已上线验证 |
| 阻塞/过期 | 红色 | 证据过期、项目阻塞、发布失败 |
| 中性 | 深夜蓝/灰 | 导航、正文、辅助信息 |

颜色只表达语义，不用颜色替代文字状态。

## 4. 组件规则

- KPI 卡：最多四个，必须能解释“为什么重要”；
- 状态标签：显示中文状态 + 必要的英文机器值；
- 证据卡：显示来源、采集时间、置信度、缺口和核验动作；
- 负责人：头像/姓名/角色/截止时间成组显示；
- 按钮：每个页面最多一个主动作，其他动作降级为次按钮；
- 图表：必须显示时间范围、单位、来源和数据新鲜度；
- 表格：优先展示项目、阶段、负责人、风险、下一步，不堆叠原始文本；
- 空状态：解释为什么为空以及下一步如何产生数据；
- 错误状态：显示失败原因、是否可重试和最近回执。

## 5. 页面标准

### 综合机会地图

参考第三版设计稿，负责组合趋势、四类机会分布、需要关注、机会详情和决策队列。

### 机会详情 / 证据链

重点是“为什么值得做”：机会摘要、证据链、竞品/替代方案、路线评分、风险、权利审查和下一步决策。不能做成普通长文章页面。

### 项目管理 / 开发发布

重点是“现在做到哪一步”：周版本、任务泳道、负责人、阻塞、QA、RC、发布回执和结果回流。不能把排期、开发中和已上线混成一个状态。

### 运行与 Agent

重点是“系统是否真的执行”：运行状态、来源、耗时、产物、缺口、错误、重试和业务回执。不能只显示一个“运行中”动画。

## 6. 响应式与无障碍

- 桌面端以 1440px 画布为主要基准；
- 1280px 以下将右侧关注栏移到主内容下方；
- 移动端保留筛选、状态、主动作和关键证据，复杂图表可横向滚动；
- 所有颜色状态同时提供文字；
- 键盘可到达主导航、筛选、队列和主动作；
- 对比度、焦点环、跳过导航和错误提示必须保留。
