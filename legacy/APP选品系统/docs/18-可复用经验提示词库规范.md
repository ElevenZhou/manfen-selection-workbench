# 可复用经验提示词库规范

提示词库保存已经验证过、可以跨项目复用的动作；制作档案保存单个项目的完整上下文。两者分开，避免把项目事实和通用经验混成一段大提示词。

首批标签：美术优化、GitHub Actions APK 发布、关卡难度、SDK 接入、体验验收。

GitHub Actions APK 发布模板已验证可用，覆盖 Android SDK 36 / JDK 21、Gradle wrapper 检查、Debug 与可选 Release、Artifacts、latest-apk 和 v* Release。

保留原则：能明确触发场景、动作和验收证据的提示词才保留；一次性项目背景、重复的产品介绍、没有实际验证记录的技巧和泛泛的励志描述不进入提示词库。

使用方式：从线上“提示词库”复制通用动作；从制作档案复制带项目事实的开工提示词；组合后交给开发台，并保存修改后的项目版本。
